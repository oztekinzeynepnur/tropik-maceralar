# 🌴 Tropik Maceralar Web Projesi

Bu proje, tropik tatil temalı bir web sayfasıdır. TailwindCSS ile tasarlanmış, GSAP, AOS ve ScrollTrigger gibi kütüphanelerle zenginleştirilmiştir. Mobil uyumlu (responsive) tasarıma sahiptir ve kullanıcıya etkileşimli, akıcı bir deneyim sunar.

## 🚀 Kullanılan Teknolojiler
- **HTML5**
- **TailwindCSS**
- **JavaScript**
- **GSAP (GreenSock)**
- **AOS (Animate on Scroll)**
- **ScrollTrigger**

## 🎯 Özellikler
- 🌈 Renkli ve modern tasarım
- ✨ Scroll animasyonları (AOS ve GSAP)
- 📱 Responsive yapı (mobil uyumlu)
- 🎬 Açılır menü & modal içerik
- 🎨 Temiz ve düzenli HTML yapısı
